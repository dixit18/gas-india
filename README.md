# Gas India — School Compliments (Positive Only)

Clone of Gas USA (7.4M installs, #1 beating TikTok, shut by Discord Nov 2023).
Never launched in India. No positive-only Hindi polls.

## Thinking
- 250M students, crave validation, fear bullying. Pre-written nice polls only, no DM, flame inbox, God Mode Rs 99/mo.
- 4 people did $7M US. Pure MERN, viral school-by-school.

## Contradict
- Schools call distraction, needs 100k for money, US growth stalled.
- Fix: colleges 18+ first (DU/Pune), Hinglish, kill if D7 <25%.

## MVP
- School/class pick, hourly polls, flames, God Mode hints
- Stack: PWA, Node, Mongo, Firebase push, AI poll-gen + moderation

## Run

npm install
cp .env.example .env
